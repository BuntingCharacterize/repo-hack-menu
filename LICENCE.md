## 🧩 About

**R.E.P.O. Menu** is a curated list of R.E.P.O. open-source tools:

- **Overlays** — on-screen helpers, layout notes, value tracker, extraction route viewer
- **Quality-of-Life Helpers** — loot catalog, config notes, overlay notes
- **Research Notes** — scrape routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Run Helpers
- Extraction Route Viewer — study paths between rooms
- Value Tracker — track collected item values on screen
- Replay Notes — record and review run segments
- Playback Speed — adjust review playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Loot Catalog — browse items, crates, and value tiers
- Custom Loadout Notes — organize cosmetic choices
- Visibility Notes — improved object readability

### 🏋️ Practice Layout
- Segment Study Notes — break long runs into study chunks
- Gravity Flip Notes — observe physics changes during study
- Timer Buffer Notes — chain maneuvers in the review editor
